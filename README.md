# 정인영 | UI/UX Publisher Portfolio

정인영의 UI/UX 퍼블리싱, 디자인 시스템, 웹 접근성 및 주요 프로젝트 경험을 소개하는 반응형 포트폴리오입니다.

## 주요 섹션

- **Intro**: 소개와 주요 행동 링크
- **Philosophy**: 디자인 철학과 강점
- **Skills**: 기술 역량, 교육 및 자격
- **Showcase**: 주요 프로젝트 카드
- **Archive**: 경력 목록과 페이지네이션
- **Contact**: 연락처 및 협업 제안

## 기술 구성

- 정적 HTML, CSS, JavaScript
- 디자인 토큰, 반응형 스타일, 컴포넌트 규칙을 `assets/css/style.css`에서 직접 관리
- 외부 CSS 프레임워크 없이 프로젝트 내부 스타일 계층 사용
- `assets/data/archive.json`을 불러와 데스크톱 표와 모바일 카드 목록 표시
- 프로젝트 아카이브는 페이지당 8개 항목 표시

## 디자인 시스템 규칙

- 색상은 `assets/css/style.css`의 CSS 변수(`--color-*`)를 우선 사용하고, 새 색상은 기존 배경·텍스트·강조·테두리 역할에 맞춰 추가
- 주요 강조색은 teal, 보조 강조색은 cyan으로 사용하고, 텍스트와 배경은 충분한 명도 대비를 유지
- 간격과 모서리는 `--space-*`, `--radius-*` 토큰을 기준으로 사용
- HTML의 `ui-*` 클래스는 프로젝트 내부 스타일 계층이며, 새 컴포넌트는 `portfolio-card`, `archive-*`처럼 역할이 드러나는 이름으로 정의
- 섹션·카드·버튼은 기존 공통 컴포넌트 패턴을 우선 재사용해 시각적 일관성 유지
- 공통 컴포넌트의 스타일 변경은 관련 화면과 반응형 상태를 함께 확인하고, 특정 화면에만 필요한 규칙은 범위를 한정해 작성
- 포커스 표시, 버튼 상태, 대체 텍스트 등 키보드·보조기기 사용에 필요한 접근성 유지

## 반응형 규칙

- 화면 구간은 em 단위 기준으로 관리: 모바일 `42.5em`(680px) 이하, 태블릿 `42.5625em`(680px 초과)부터 `74.999em` 미만, 데스크톱 `75em`(1200px) 이상
- 내부 `sm`, `md`, `lg` 레이아웃 유틸리티는 각각 `42.5em`, `53.75em`(860px), `75em`을 기준으로 적용
- 미디어 쿼리의 너비 단위는 px 대신 em 사용
- 모바일에서는 섹션 텍스트를 왼쪽 정렬하고, 태블릿과 데스크톱에서는 가운데 정렬
- 모바일 Featured Showcase 카드 목록은 가로 스크롤과 터치 스와이프 지원
- 이미지의 크기와 비율은 유지하고, 반응형 조정은 필요한 경우 배치·컨테이너를 중심으로 적용

## 타이포그래피 규칙

- 기본 글꼴은 Pretendard GOV를 사용하며, 본문과 UI 텍스트는 기존 글꼴 상속 규칙 유지
- 제목은 `.typography-h1`부터 `.typography-h6`까지의 계층을 우선 사용하고, 새 제목 스타일을 추가하기 전에 기존 계층으로 표현 가능한지 확인
- 데스크톱 제목 크기 기준: h1 `3.5rem`, h2 `3rem`, h3 `1.75rem`, h4 `1.25rem`, h5 `1rem`, h6 `0.875rem`
- 모바일(최대 `42.5em`) 제목 크기 기준: h1 `2rem`, h2 `1.875rem`, h3 `1.5rem`; 나머지는 공통 제목 크기를 유지
- 본문·보조 문구·라벨은 의미와 중요도에 맞춰 크기와 굵기를 구분하고, 강조색은 핵심 정보에 한정해 사용

## 폴더 구조 및 파일 배치

```text
.
├── index.html                 # 포트폴리오 페이지 마크업
├── assets/
│   ├── css/
│   │   └── style.css          # 디자인 토큰, 내부 스타일, 컴포넌트와 반응형 규칙
│   ├── data/
│   │   └── archive.json       # 경력 아카이브 데이터
│   ├── img/                   # 이미지 및 로고 에셋
│   └── js/
│       └── main.js            # 페이지 상호작용
└── .vscode/                   # 프로젝트 미리보기 작업 설정
```

- 기능별 소스는 해당 디렉터리에 배치하고, HTML에는 콘텐츠 구조와 페이지 구성을 유지
- 이미지와 데이터 파일은 `assets/img/`, `assets/data/`에 종류별로 분리하고 관련 없는 파일을 루트에 추가하지 않음
- 새 파일은 기존 명명 방식과 경로 구조를 따르고, 파일 이동 시 HTML·CSS·JavaScript 참조도 함께 갱신

## 상호작용

- 모바일 Featured Showcase 카드 목록은 가로 스크롤과 터치 스와이프 지원
- 아카이브 페이지 이동 시 현재 위치를 유지하며, 모바일 입력 이동은 목록 영역으로 스크롤
- 모바일 내비게이션은 토글 버튼, 바깥 영역 클릭, Escape 키로 닫을 수 있음

## 로컬 미리보기

필요 조건: Node.js

VS Code에서 **Tasks: Run Task → Portfolio browser preview**를 실행하면 `http://127.0.0.1:4173`에서 미리보기를 시작합니다. 별도의 스타일 빌드나 패키지 설치는 필요하지 않습니다.

## 배포

GitHub Pages가 `master` 브랜치의 저장소 루트를 게시합니다. HTML, CSS, JavaScript 및 에셋 변경 사항을 `master`에 게시하면 배포됩니다.
